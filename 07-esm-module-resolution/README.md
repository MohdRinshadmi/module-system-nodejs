This sample demonstrates how module resolution works with ESM

Dependencies
This example requires you to install some third-party dependencies from npm.

If you have pnpm installed, you can do that with: pnpm install 
Otherwise install pnpm globally - npm install -g pnpm then pnpm install

Alternatively, if you prefer to use another package manager, make sure to delete the pnpm-lock.yaml file before using it.

If you want to use npm, you can run:

npm install
If you want to use yarn, you can run:

yarn install
Run
node main.js
